Privacy Policy

Last updated: May 2026

Uncle Joe's Guardian ("the Extension") is a classroom management tool designed for use by teachers to monitor and manage student Chrome browsers in an educational setting. This Privacy Policy explains what data is collected, how it is used, and how it is protected.

1. Who This Extension Is For

This Extension is intended for use by teachers and school administrators. It is installed on student devices with the knowledge and consent of the school or educational institution. It is not intended for use by or directed at children independently.

2. Data Collected

The Extension collects the following data from student devices when the extension is active:

  • Active tab URL and title – to display the current website a student is visiting
  • Tab list – to show all open browser tabs to the connected teacher
  • Screenshots – browser screenshots taken on demand by the teacher or on a scheduled interval
  • Browsing activity – page visit history recorded during the active session for timeline review
  • Google account name – optionally retrieved to identify the student device
  • A randomly generated 5-digit class code – used to link the student to their teacher's classroom

3. How Data Is Used

All collected data is used solely for classroom management purposes:

  • Displaying live student screens to the teacher dashboard
  • Allowing teachers to close tabs, lock screens, or block websites
  • Providing teachers with a browsing timeline for monitoring
  • Sending messages from teacher to student devices

Data is not sold, shared with third parties, used for advertising, or retained beyond the active session. All data is transmitted in real time to the teacher's dashboard and is not stored permanently on any server.

4. Data Storage

Session data (screenshots, tab lists, browsing history) exists only in memory while the server is running and is automatically cleared when the session ends or the server restarts. No student data is written to a permanent database.

The following data is stored locally in the browser using chrome.storage.local:

  • Student's chosen display name
  • The student's unique 5-digit class code
  • Lock state and tab limit settings

5. Data Transmission

All data is transmitted over an encrypted WebSocket connection (WSS) and HTTPS between the student device and the teacher's dashboard server. No data is transmitted to any third-party service.

6. Permissions Used

The Extension requests the following Chrome permissions, each used solely for its stated classroom management purpose:

  • tabs – to read and display open tabs to the teacher
  • activeTab – to capture the current tab screenshot
  • storage – to save the student's name and class code locally
  • scripting – to inject content scripts for chat bubbles and YouTube filtering
  • windows – to open and manage the lock screen window
  • notifications – to show teacher messages and alerts to the student
  • declarativeNetRequest – to block websites as configured by the teacher
  • identity – to optionally retrieve the student's Google account display name

7. Children's Privacy

This Extension is deployed by schools and teachers, not directly by students. Schools are responsible for obtaining appropriate parental or guardian consent in accordance with applicable laws (including COPPA, FERPA, or local equivalents) before deploying this Extension on student devices.

8. Teacher Dashboard

The teacher dashboard stores account credentials (username and hashed password) in the teacher's own browser localStorage. No account data is transmitted to or stored on a third-party service. Teachers are responsible for keeping their login credentials secure.

9. Changes to This Policy

This Privacy Policy may be updated from time to time. Continued use of the Extension after changes constitutes acceptance of the updated policy.

10. Contact

For questions about this privacy policy or data practices, please open an issue on our GitHub support page or contact the extension developer directly.
